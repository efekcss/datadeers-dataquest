# DataDeers | ASA DataQuest Yarışması

Bu github repo'sunda ASA DataQuest yarışması için yaptığım çalışmalar; Rscript, Rmarkdown, Quarto (.Rqmd), Python, Markdown(.md) dosyaları ve bazı dokümantasyon dosyaları yer alıcak. 
Veri gizliliğinin yanı sıra dosyaların büyük olması sebebiyle tabiki data paylaşılmayacak ancak küçük ölçekte bazen gerekli görülen data parçaları, örneklemler buraya yüklenebilir.
